# Política de segurança

## Versões suportadas

Apenas a última versão publicada (tag mais recente) recebe correções de segurança.

## Como reportar

Encontrou uma vulnerabilidade? **Não abra issue pública.** Use o
[reporte privado do GitHub](https://github.com/lucassantana2301-bot/finops-sentinel/security/advisories/new)
com o passo a passo para reproduzir e o impacto estimado.

- Confirmação de recebimento em até 3 dias úteis.
- Correção ou plano de mitigação em até 30 dias, conforme a severidade.
- Crédito no advisory, se desejar.

## Escopo

Vazamento de credenciais ou dados de billing, bypass da API key, SSRF nos conectores e webhooks, injeção via arquivos CSV importados e problemas nas imagens Docker publicadas.
