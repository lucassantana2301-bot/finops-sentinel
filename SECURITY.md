# Política de segurança

Encontrou uma vulnerabilidade? Não abra issue pública. Use o [reporte privado do GitHub](https://github.com/lucassantana2301-bot/finops-sentinel/security/advisories/new) com os passos para reproduzir.

Escopo principal: vazamento de credenciais ou dados de billing, bypass da API key, SSRF nos conectores e webhooks, injeção via arquivos importados.
